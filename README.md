# Optical SDN Fault Simulator

I built a simple simulated lab environment on my local machine inspired by optical SDN principles.

## Features Implemented
* **Optical Node Simulator:** A Python-based simulator representing optical nodes.
* **REST API Endpoints:** Used for provisioning and retrieving telemetry data.
* **Controller Script:** Periodically polls the network state to ensure stability.
* **Fault Simulation:** Simulates critical issues such as optical power degradation and BER (Bit Error Rate) increase.

The system parses structured JSON data and logs alerts in real time, simulating basic fault monitoring and automation workflows.
